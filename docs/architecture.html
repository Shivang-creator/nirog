complaintthe memory itself

raw_text — the patient's own words, never rewritten
body_region — deterministic lexicon, not a model
region_source — lexicon | inherited | none
region_inherited_from → complaint(id)
embedding VECTOR(1024) · nullable on purpose
embed_model — which backend actually answered

Complaint and vector are written in one statement, in one row — no ETL, no window where a memory exists but is not yet searchable, and no way for the two to disagree.

The complaint is still recorded when the embedder is down: losing the index is degraded service, losing the words is data loss.

VECTOR INDEX complaint_embedding_idx

(patient_id, embedding vector_cosine_ops)

Cosine, not L2. Titan does not guarantee unit norm, and under L2 a long complaint sits far from a short one meaning the same thing.

patient_id as prefix — C-SPANN descends one patient's span, so latency follows one history, not the clinic's size. A query that cannot say “search everyone” cannot do it.

Cut-offs are per embedding space: 0.85 Titan, 0.55 offline. Distances across spaces are not comparable.

Deterministic core — no model touches this · the embedding finds candidates; a fixed rule decides what they mean

resolveRegion()

“the ache is back again” names no body part — back there means returned. Read alone it is unclassifiable.

Read against what this patient said in July, it is obviously lumbar. Memory supplies the region and region_source records that it was inherited, so a doctor can see the link was inferred.

recurrence rule

≥ 3 separate visits naming one body region within 90 days (watch: 2 in 30). Arithmetic, no scoring — a doctor can check it on paper in ten seconds.

It counts visits, not complaints. Three sentences in one appointment are one presentation; counting complaints would let a talkative patient trip the flag on day one.

SBAR assembly clinical/sbar.ts

Every field built from rows. An earlier plan had gpt-oss rewrite it into prose — but a model smoothing “the ache is back again” into “recurrent lumbar pain” invents a claim the patient never made.

It reports a pattern; it does not diagnose.

The degradation contract — cross-cutting

Every memory read returns MemoryOutcome{ ok, value, degraded, reason }, never a bare array, so it is impossible to consume a result without handling the case where memory was down. A failed lookup is never an empty list: “no prior complaints” and “could not check” would render identically, and a doctor reads that absence as reassurance. Absence of evidence is not evidence of absence — and an agent that cannot tell the difference should not be near a patient.
